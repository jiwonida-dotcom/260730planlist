2프로세스 개선

AS-IS에서 요금제 선택은 신청서 흐름 중간의 조건 분기 뒤에 숨어 있었습니다. 가장 어려운 판단이 흐름 후반에, 조건부로 나타난 셈입니다. TO-BE는 분기를 제거하고 판단을 개통 방법 직후로 고정 배치합니다.

AS-IS 개통 방법→ 상품 정보→ 가입 방법→ 요금제 선택됨?
예→ 가입자 유형→이후 동일
아니오→ 요금제 선택→ 가입자 유형→이후 동일
TO-BE 개통 방법→ 요금제 선택됨?
예→ 상품 정보→ 가입 방법→ 가입자 유형→이후 동일
아니오→ 요금제 선택→ 상품 정보→ 가입 방법→ 가입자 유형→이후 동일
분기는 사라지지 않고 앞으로 이동했습니다. AS-IS는 요금제 보유 여부를 가입 방법 선택 뒤에 판정해, 미선택 사용자가 흐름 후반에 가장 어려운 판단을 만났습니다. TO-BE는 같은 판정을 개통 방법 직후로 옮깁니다.

① 가장 어려운 판단을 여정 초반에 완결시켜 이후를 단순 진행으로 만든다
② 판정이 앞당겨져 상품 정보 입력 이후 구간이 두 경로 모두 동일해지므로 이탈 계측이 단순해진다
③ 개통 방법이 선행 확정되므로 미지원 요금제를 목록에서 사전 필터링할 수 있다

3화면 개선

배너를 제거하고 그룹핑을 해체해 단일 목록 + 탐색 컨트롤 구조로 재편했습니다. 선택 피드백은 리스트 재배치에서 카드 인라인 상태 변경으로 바꾸고, 확정 수단은 sticky 바로 이관해 선택과 확정을 한 시야에 묶었습니다.

AS-IS
카드 클릭 → 화면 최상단 점프 → 위치 상실 → 접힌 카테고리 6개 지나 최하단까지 재스크롤 → '다음'
TO-BE
카드 클릭 → 그 자리에서 보더·라디오 메인 컬러 전환 → sticky 바에 요금제명·요금 요약 + '개통 시작하기' 즉시 노출
AS-IS
자동 회전 배너 클릭 = 즉시 선택 / 아코디언 7개 중 6개 접힘 · 개수·가격 힌트 없음
TO-BE
배너 제거 · 실적 기반 주간(BEST) 탭 / 단일 목록 + 개수·필터·정렬·비교 (전 탭 공통)

4데이터 · 노출 규칙

화면 구성에 필요한 데이터는 전부 기존 요금제 데이터와 기존 기능으로 충족됩니다. 백오피스 신규 관리 항목은 없으며, 유일한 연동 지점은 사용 여부 조건입니다.
